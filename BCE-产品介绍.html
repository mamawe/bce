📌 产品定位

BCE (Business Context Engine) 是一款 AI 原生的业务上下文引擎，专注于解决业务团队"知识散落、信息断层、决策无痕"的痛点。 它通过结构化的方式摄入业务文档（周报、复盘、会议纪要），将非结构化的知识转化为可查询、可追溯、可推理的结构化数据资产。

📈 指标波动归因

自动关联历史文档中关于同一指标的归因、决策与结果，追溯"为什么下降 12%"背后的完整故事

"为什么 GMV 最近下降了？" → 返回渠道预算骤减40% → 决策：临时调配 → 结果：3周后恢复

🔢 数值事实问答

基于宽表 metric_facts 实现 NL→SQL，精确到个位数的指标查询

"肉类Q3毛利率排名" → LLM 生成 SQL → 查询宽表 → 返回精确数值

🕸️ 实体关系发现

自动从文档中提取因果关系，构建实体关联图谱

"渠道B预算 → 新客获取量 → GMV" 自动建立 Tier-1 显式关系

📚 决策追溯重建

每条事件关联决策动作、责任人、应对结果，形成完整决策闭环

"上次遇到类似情况怎么处理的？" → 定位历史匹配事件 + 决策 + 成败标记

💬 智能问答系统

采用"意图路由 + Handler 分发 + LLM 兜底"的多层架构。核心原则：LLM 不参与计算，所有计算在 SQL/Python 层完成。 数值型问题统一走 NL→SQL 查宽表（精确快），叙事型问题走时间线路径（有因果链），两者不竞争各管各的层。

METRIC_SQL

数值查询

排名/最高/最低/趋势 → LLM 生成 SQL → 查宽表 metric_facts → 格式化返回精确数值

FACTUAL

事实查询

"GMV 最新值" → 读 metric_value + metric_unit + metric_delta_pct 字段，格式化输出

AGGREGATION

聚合统计

波动次数 / 高频归因 / 子实体贡献度 → Python 预计算 → 文本格式化

COMPARISON

对比分析

多实体并排对比 → SQL 批量查预计算指标 → LLM 解释差异

ANALYTICAL

归因推理

"为什么下降" → 收集时间线 + 指标 + 子实体 → LLM 推理 → 校验 → 降级规则

WHAT_IF

情景分析

"涨价 10%" → Python Decimal 精确计算波动率变化 → LLM 解释

🔌 流式输出 (SSE)

POST /api/v1/ask/stream 支持 Server-Sent Events 逐 chunk 返回，前端 ChatPanel 消费 ReadableStream， 实现打字机效果。格式：{"type": "chunk", "content": "..."}

🔍 三层证据调和机制

设计原则：不自动"定罪"，冲突只标记人做最终裁判。 新证据涌入时自动评估历史证据的可信度。

📉 Layer 1 · 置信度衰减

effective_score = base × max(0.3, 1 - 0.05 × weeks)
越旧的证据权重越低，保留底线 30%

🤖 Layer 2 · LLM 冲突检测

4 档判定：一致 / 补充 / 部分矛盾 / 完全推翻
数字冲突自动进入 review_queue

🛡 Layer 3 · 共识保护

≥3 份证据支持的共识，单份推翻不生效
标记 NEEDS_REVIEW 等待人工裁判

证据证据评分体系

reason_code 基础分 语义
FIRST_MENTION 5.0 实体首次出现源文档
FINAL_RESOLUTION 5.0 事件的最终解决文档
FAILED_CASE 4.0 失败案例 — 经验教训价值
HIGH_SIMILARITY 3.0 与已知事件高度相关
REGULAR 2.0 普通提及

🔗 跨实体关系发现

3 级置信度分层：显式因果自动入库，LLM 推断标 source=llm_inferred，时序共现需≥2 次升级。 低置信度且 4 周无新证据的候选自动清除。

T1

显式因果 · 置信度 0.9

文档中明确使用"导致"、"使得"、"因为...所以"等句式，自动入库

T2

LLM 推断 · 置信度 0.6

基于上下文语义推断的隐藏关系，标 source=llm_inferred 供人工复核

T3

时序共现 · 置信度 0.3

多文档中反复共同出现，≥2 次共现升级为 T2 候选

前端展示： RelationshipBar 组件以水平 chips 展示关联实体，可点击跳转；默认只展示置信度 ≥ 0.5 的关系。

💎 设计哲学

👨‍⚖️ 不自动"定罪"

冲突只标记人做最终裁判。review_queue 机制保证每条矛盾数据可追溯、可人工裁定。

📊 置信度分级

0.3 / 0.6 / 0.9 三层，前端默认展示 ≥ 0.5。用户可纠正每个自动化决策。

⏳ 衰减 + Pruning

过时证据自动降权，候选关系 4 周无新证据自动清除。系统会"遗忘"。

🔀 数据库即真相

LLM 只负责推理，不存储结果。每次问答重新从 DB 查询计算，保证数据源头一致。
